# 🖥️ Point Tech Marsa - Boutique en Ligne

Bienvenue sur **Point Tech Marsa**, une boutique en ligne complète de matériel et composants informatiques destinée aux clients tunisiens.

## ✨ Caractéristiques

### 🌐 Interface
- **Langue**: Français
- **Localisation**: Tunisie
- **Monnaie**: Dinar Tunisien (DT)

### 🛍️ Fonctionnalités
- **Catalogue de produits**: 20 produits informatiques variés
- **Recherche et filtrage**: Par catégorie et par prix
- **Panier persistant**: Les produits restent dans le panier même après fermeture
- **Gestion du panier**: Ajouter, modifier quantité, supprimer
- **Paiement à la livraison** (Contre Remboursement - COD)
- **Formulaire de commande**: Avec informations de livraison complètes
- **Confirmation de commande**: Message de confirmation instantané

### 📦 Catégories de Produits
1. **Ordinateurs**: Portables et Desktops
2. **Périphériques**: Claviers, souris, écrans, casques, webcams
3. **Imprimantes**: Laser et couleur
4. **Accessoires**: Disques SSD, RAM, alimentations, processeurs, etc.

## 🚀 Démarrage Rapide

### Installation
1. Clonez le repository
```bash
git clone https://github.com/DidofidoTn/POINT-TECH-MARSA.git
cd POINT-TECH-MARSA
```

2. Ouvrez simplement `index.html` dans un navigateur web

### Fichiers de la projet
```
POINT-TECH-MARSA/
├── index.html          # Page d'accueil
├── shop.html          # Boutique et catalogue
├── cart.html          # Panier d'achat
├── checkout.html      # Paiement et livraison
├── style.css          # Feuille de styles
├── script.js          # Logique JavaScript
├── products.json      # Catalogue de produits
└── README.md          # Documentation
```

## 📄 Pages

### Index (Accueil)
- Présentation de Point Tech Marsa
- Avantages clés (livraison rapide, paiement COD, produits certifiés)
- Catégories populaires
- Appel à l'action vers la boutique

### Shop (Boutique)
- Catalogue de 20 produits
- **Recherche**: Recherche en temps réel par nom ou description
- **Filtres**: 
  - Par catégorie
  - Tri par prix (bas/haut)
- Affichage du statut de stock

### Cart (Panier)
- Liste complète des articles
- Modification de quantité
- Suppression d'articles
- Calcul automatique du total
- Bouton procéder au paiement

### Checkout (Paiement)
- Formulaire de livraison complet
- Sélection de ville (liste des villes tunisiennes)
- Méthode de paiement: **Contre Remboursement (COD)**
- Résumé de la commande
- Confirmation avec numéro de commande

## 💾 Stockage Local
- **Panier**: Stocké dans `localStorage` pour persistance
- **Commandes**: Historique des commandes sauvegardé en local

## 🎨 Design
- Interface moderne et épurée
- Responsive design (adapté mobile/tablette/desktop)
- Gradients bleus pour cohérence visuelle
- Icônes emoji pour les catégories

## 📝 Catalogue de Produits
Le fichier `products.json` contient:
- Ordinateurs portables et desktops
- Périphériques (clavier, souris, écrans)
- Imprimantes
- Composants (RAM, SSD, processeurs)
- Accessoires informatiques

Chaque produit inclut:
- Nom et description
- Prix en DT
- Catégorie
- Stock disponible
- Emoji/icône

## 🔧 Technologies Utilisées
- **HTML5**: Structure sémantique
- **CSS3**: Responsive design et animations
- **JavaScript vanilla**: Gestion du panier, filtres, validation
- **LocalStorage**: Persistance des données

## 📦 Méthode de Paiement
- **Paiement à la Livraison**: Entièrement compatible
- Les clients paient directement au livreur
- Aucune information de paiement sensible stockée

## 🌍 Localisation Tunisie
- Monnaie: Dinar Tunisien (DT)
- Villes principales sélectionnables:
  - Tunis, Ariana, Ben Arous, Manouba, Marsa
  - Sfax, Sousse, Monastir, Kairouan, Gabès
  - Autre (pour villes non listées)
